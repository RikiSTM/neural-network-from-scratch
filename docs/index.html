🧠 Neural Network From Scratch

Unboxing the "black box" of Deep Learning using pure NumPy.

🎯 The "Why"

In an era where calling model.fit() in PyTorch takes 3 lines of code, it's dangerously easy to treat Neural Networks as magic black boxes. This repository is my deliberate journey to strip away the abstractions and rebuild the core engine of Deep Learning from first principles.

If you don't know how backpropagation flows through a computational graph, you can't debug why your loss is NaN or why your gradients are vanishing. This project is about owning the math.

🛠️ Core Implementations

  • Tensor Operations: Matrix multiplication and broadcasting.
  • Forward Pass: Data flowing through Multi-Layer Perceptrons (MLP).
  • Activations: LeakyReLU (solving the Dying ReLU problem) & Softmax.
  • Loss Functions: Cross-Entropy paired with Softmax.
  • Backpropagation: Manual implementation of the Chain Rule.
  • Optimizers: AdamW (Adam with Decoupled Weight Decay).
  • Regularization: Inverted Dropout & L2 Weight Decay.

💡 Key Engineering Insights

1. Space Warping (The Manifold Hypothesis)

Hidden layers don't "think" like humans. They act as hands that stretch, fold, and warp the input space (like a rubber sheet) into higher dimensions. A non-linear problem (like Spirals) becomes linearly separable in this warped space.

2. The Chain Rule is just a messenger

Backpropagation is simply passing the "blame" (gradient) backward through the pipes (weights), multiplied by the local derivative.

3. Softmax + Cross-Entropy Power Couple

The combined derivative simplifies beautifully to: Gradient = Prediction - Target.
